# AutoCAD 철도 배선 분기기 자동 작도

Windows AutoCAD 모델 공간에서 사용하는 AutoLISP입니다. 직선 본선의 평행 유치선을 만들고, 등록한 분기기 블록을 복제해 본선에 맞춰 회전·이동합니다. 이론교점에서 시작하는 분기 직선과 유치선에 접하는 원호를 함께 그립니다.

## 시작하기

1. `APPLOAD`로 `rail_turnout.lsp`를 로드합니다. 표준 분기기는 `RAILTURN`, `RAILFAN`, `RAILCROSS`에서 바로 선택합니다. 사용자 정의 분기기는 `RAILMAKE`로 만들거나 기존 블록을 `RAILSETUP`으로 등록합니다.
2. 본선과 유치선 중심선은 같은 높이에 있는 수평 `LINE` 객체를 사용합니다. 도면이 mm 단위라면 선간격과 반지름도 mm로 입력합니다.
3. 블록의 점을 지정할 때는 끝점·교점 등 필요한 객체 스냅을 사용합니다. 블록의 삽입점이 본선 위의 배치 기준점과 일치하면 삽입점 스냅도 사용할 수 있습니다.

## 표준 분기기 라이브러리

`RAILTURN` 또는 `RAILFAN`의 첫 프롬프트에서 `F8`처럼 규격명을 입력하고 분기 방향을 고릅니다. 진행 방향 기준 왼쪽은 `Left`, 오른쪽은 기본값인 `Right`입니다. `STD-F8-L` 또는 `STD-F8-R`로 규격과 방향을 한 번에 선택할 수 있습니다. 같은 이름의 사용자 등록이 있으면 `STD-` 접두사가 붙은 이름으로 표준을 선택합니다.

표의 길이는 미터이며 첫째 길이는 **배치 기준점에서 이론교점까지**, 둘째 길이는 **이론교점에서 분기 끝점까지 본선 방향으로 잰 거리**로 적용합니다. 도면 단위가 mm면 **미터당 도면 단위**에 `1000`, m면 `1`을 입력합니다. 기본값은 현재 세션의 마지막 입력값이나 도면의 `INSUNITS` 설정에서 가져옵니다. 곡선 반지름과 추가 직선 길이는 기존처럼 도면 단위로 입력합니다.

| 규격 | 기준점 → 이론교점 (m) | 이론교점 → 분기 끝점의 본선 방향 거리 (m) | 분기각 |
| --- | ---: | ---: | ---: |
| F8 | 12.144 | 14.170 | 7°09′10″ |
| F10 | 14.655 | 17.147 | 5°43′29″ |
| F12 | 17.363 | 20.514 | 4°46′19″ |
| F15 | 21.249 | 25.910 | 3°49′06″ |
| F18.5 | 32.774 | 35.199 | 3°05′39″ |
| F26 | 45.412 | 46.541 | 2°07′59″ |
| F46 | 45.105 | 81.971 | 1°18′46″ |

표준 블록은 접속 작도가 성공할 때 설치 위치에 바로 배치됩니다. 별도 샘플 블록을 도면에 놓을 필요가 없습니다.

## RAILMAKE — 분기기 블록 생성 및 등록

빈 도면에서 `RAILMAKE`를 실행하면 빨간 기준선, 세로 표시선, 원, 채운 삼각형, 규격 문자가 들어 있는 블록을 만듭니다. 아래 순서로 입력합니다.

1. **표시 문자 → 분기 방향 → 블록 이름**을 지정합니다. 기본 문자는 `F8`입니다. 진행 방향인 +X를 기준으로 `Left`는 +Y, `Right`는 −Y입니다. 기본 블록 이름은 `F8-L` 또는 `F8-R`처럼 구성되며 같은 이름의 기존 블록은 덮어쓰지 않습니다.
2. **배치 기준점에서 이론교점까지의 거리 → 이론교점부터 분기 끝까지의 본선 방향 거리 → 분기 입력 방식**을 지정합니다. 두 거리는 도면 단위로 입력합니다.
   - **`Ratio`** (기본값)에서는 분기비 `1:N`의 분모 `N`을 입력합니다. 예를 들어 본선 방향 거리가 `7200`이고 `N=8`이면 분기 끝점은 본선에서 `900` 떨어집니다.
   - **`Angle`**에서는 본선과 분기선 사이의 각도를 도 단위로 입력합니다. 예를 들어 `7.12501635`는 약 `1:8`에 해당합니다. 각도는 `0°`보다 크고 `90°`보다 작아야 하며, 분기 방향은 앞 단계의 `Left` 또는 `Right`를 따릅니다.
3. 모델 공간에서 샘플 블록을 놓을 점을 찍습니다. 선택한 점이 블록 삽입점이며 기준선은 WCS +X 방향입니다. 생성 직후 현재 도면 세션에 자동 등록되므로 바로 `RAILTURN` 또는 `RAILFAN`을 실행할 수 있습니다.

블록은 DWG에 저장됩니다. 도면을 다시 열고 저장된 블록을 자동 작도에 사용하려면 `RAILSETUP`으로 등록합니다. 삼각형이 윤곽만 표시되는 도면에서는 `FILLMODE`를 `1`로 설정한 뒤 `REGEN`을 실행하면 채움이 표시됩니다.

새로 생성하는 표준형과 `RAILMAKE` 블록의 문자 높이는 `2.3 m`, 세로 표시선 전체 길이는 `2 m`, 원 반지름은 `1 m`입니다. mm 도면에서는 각각 `2300`, `2000`, `1000`입니다. `RAILMAKE`는 현재 세션의 마지막 표준형 환산값 또는 도면의 `INSUNITS`를 따르며, 둘 다 없으면 도면 단위로 `2.3`, `2`, `1`을 사용합니다. 이미 배치된 블록은 생성 당시의 치수를 유지합니다.

## RAILSETUP — 분기기 등록

샘플 분기기 블록 하나를 선택한 뒤 아래 순서로 점을 지정합니다.

| 명령창 표시 | 지정할 점 |
| --- | --- |
| Placement datum on its main axis | 실제 배치 때 본선에 맞출 블록 기준점 |
| Second point in the turnout forward direction | 블록 본선 축 위의 두 번째 점. 기준점에서 분기가 진행되는 방향으로 선택 |
| Theoretical intersection (PI) | 블록의 이론교점 |
| Divergent end of the turnout | 블록 안 분기 직선의 바깥쪽 끝점 |

마지막에 `F8-L` 같은 이름을 입력합니다. 좌·우 분기기나 규격이 다른 블록은 각각 등록합니다. 같은 이름으로 다시 등록하면 갱신됩니다. 등록은 현재 도면 세션에서 재사용됩니다. 샘플 블록을 이동·삭제하거나 내부 형상을 수정한 경우 다시 등록합니다. 블록의 시작 좌표와 회전각은 임의여도 됩니다.

## RAILYARD — 유치선 일괄 생성

직선 본선을 선택하고 유치선을 만들 쪽을 찍은 뒤, **유치선 개수 → 중심선 간격**을 입력합니다. 예를 들어 개수 `4`, 간격 `5000`이면 본선에서 `5000`, `10000`, `15000`, `20000` 떨어진 평행선이 생깁니다. 양쪽에 유치선이 필요하면 반대쪽을 지정해 다시 실행합니다. 기존 평행 `LINE`을 쓸 경우에는 이 명령을 건너뛸 수 있습니다.

## RAILTURN — 분기기 배치와 접속

1. 표준 규격 또는 사용자 등록 이름을 선택합니다. Enter는 마지막으로 선택한 분기기를 사용합니다.
2. 분기기 기준점을 놓을 선로를 선택합니다. 다른 유치선에서 분기할 때는 해당 유치선을 출발 선로로 선택합니다.
3. 배치 위치를 찍고, 이어서 분기가 진행될 방향 쪽을 찍습니다. 배치점은 선택한 출발 선로에 투영됩니다.
4. 접속할 평행 유치선을 선택하고 곡선 반지름을 입력합니다. 한 번 작도한 뒤에는 Enter로 마지막 반지름을 재사용할 수 있습니다.
5. `Trim`은 원호 접점부터 분기 진행 방향 쪽 유치선 끝까지 남깁니다. `Keep`은 유치선 전체를 유지하면서 분기 직선과 원호를 생성합니다. Enter의 기본값은 `Trim`입니다.
6. 다음 유치선이나 분기 위치에 같은 명령을 반복합니다. 작도 직후 `U`로 해당 명령의 작업을 한 번에 되돌릴 수 있습니다.

분기 직선은 블록의 이론교점에서 시작해 블록 안 분기선을 따라 겹쳐 그려진 뒤, 원호가 시작하는 접점에서 끝납니다. 선택한 반지름과 유치선 위치로 두 접점을 만들 수 없으면 명령창에 이유가 표시됩니다. 유치선이 너무 짧은 경우에는 접점을 포함하도록 선을 늘린 뒤 다시 실행합니다.

## RAILFAN — 공통 사선 분기선에서 여러 유치선 접속

하나의 사선 인입선 위에 유치선마다 분기기 블록을 하나씩 배치합니다. 공통선은 수평 직선 `LINE`을 쓰며 끝에 원호가 있다면 직선 부분을 선택합니다. 대상 유치선은 공통선과 같은 높이에 있고 서로 평행해야 합니다.

1. `RAILFAN`을 실행해 공통선에서 유치선 방향으로 분기하는 표준 규격 또는 사용자 등록 블록을 선택합니다. 블록의 본선 방향이 공통선과 맞도록 회전됩니다.
2. 공통 사선 `LINE`을 선택한 뒤, 분기가 진행되는 쪽 끝을 찍습니다.
3. 연결할 유치선들을 여러 개 선택하고 Enter를 누릅니다.
4. 원호에 사용할 공통 반지름을 입력합니다. 표시된 기본값이 `Straight only`라면 Enter로 직선 접속만 작도할 수 있습니다. 각도가 남아서 원호가 필요하면 양의 반지름을 입력합니다.
5. 분기기 끝점 이후에 확보할 **추가 직선 길이**를 입력합니다. Enter는 `0`입니다. 명령은 이 길이를 기준으로 각 분기기 위치를 자동 계산합니다.
6. `Trim`은 각 유치선을 접속점에서 잘라 분기 진행 방향 쪽을 남깁니다. 공통 사선은 계속 이어집니다. `Keep`을 선택하면 유치선 전체가 유지되어 기존 교차 부분도 남습니다.

블록 분기선과 유치선이 같은 방향이면 공통선 위에서 두 선이 일직선이 되는 위치를 찾아 접속합니다. 각도가 있으면 입력한 반지름의 접선 원호를 삽입합니다. 배치 위치가 공통선 범위를 벗어나거나 접속점이 유치선 범위를 벗어나면, 해당 유치선의 핸들과 원인을 표시하고 선택 묶음 전체의 작도를 중단합니다. 성공한 묶음은 `U` 한 번으로 되돌릴 수 있습니다.

`The sample branches to the opposite side`가 나오면 먼저 공통선 진행 방향을 확인합니다. 진행 방향이 맞으면 `Mirror turnout copies ... [Yes/No]`에서 `Yes`를 선택해 같은 유치선 선택으로 다시 계산할 수 있습니다. 표준형은 반대 손 형상을 배치합니다. 사용자 등록 블록은 복제본을 반전하므로 문자와 속성의 방향을 도면에서 확인합니다.

## RAILCROSS — 두 평행 선로 사이에 건넘선 생성

1. `RAILCROSS`를 실행하고 같은 높이의 평행 `LINE` 두 개를 선택합니다. 첫 번째 선로가 시작 선로입니다.
2. 첫 선로에 놓을 분기기의 **배치 기준점**을 지정하고, 같은 선로에서 건넘선이 진행할 쪽을 한 번 더 찍습니다.
3. `F8` 같은 표준 규격 또는 사용자 등록 이름을 입력합니다. 표준형은 두 번째 선로가 있는 쪽에 맞춰 좌·우가 자동으로 결정됩니다. 등록 블록의 손이 반대인 경우에는 복제본을 반전할지 묻습니다.

같은 규격 분기기 두 개가 서로 마주 보게 배치되고, 두 분기 끝점 사이에 직선이 그려집니다. 두 평행 선로는 접속 후에도 그대로 이어집니다. 선간격이 너무 좁아 분기기 두 개가 겹치거나 어느 한쪽 선로의 길이가 부족하면 원인을 표시하고 작도를 중단합니다. 정상 작도 뒤에는 `U` 한 번으로 건넘선 전체를 되돌릴 수 있습니다.

## 시험 예

분기기 샘플을 기준점과 이론교점이 `(0,0)`, 본선 방향점이 `(10,0)`, 분기 끝점이 `(10,2)`인 형상으로 가정합니다. 본선 `(0,0) → (100,0)`의 위쪽으로 간격 `5`의 유치선을 만들고, 본선 기준점 `(0,0)`에서 +X 방향으로 반지름 `20`을 입력하면 유치선 쪽 접점은 약 `(26.9804,5)`입니다. `Trim`을 선택하면 유치선은 그 접점부터 `(100,5)`까지 남습니다.

`RAILFAN` 직선 접속 예에서 공통선은 `(0,0) → (120,12)`이고, 대상은 `y=3`, `y=6`, `y=9`에서 각각 `x=0`부터 `x=150`까지 이어지는 선입니다. 기준점과 이론교점이 `(0,0)`, 본선 방향점이 `(10,0)`, 분기 끝점이 `(10,-1)`인 블록을 등록합니다. 추가 직선 길이를 `0`으로 입력하면 분기기 기준점이 `(30,3)`, `(60,6)`, `(90,9)`에 배치됩니다. 각 분기기 끝점부터 유치선이 수평으로 이어집니다.
