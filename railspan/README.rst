Railspan | 철도 교량 개념설계 시제품
======================================

저장소 루트에서 Python 3.9 이상으로 `python -m railspan`을
실행하고 http://127.0.0.1:8765 를 브라우저에서 엽니다.
포트를 바꾸려면 `--port 8766`을 붙입니다. 모델 생성과 검토는 별도 패키지 없이 실행하며, 서버는 현재 PC의
루프백 주소에만 연결합니다. IFC 내보내기에는 IfcOpenShell이 필요합니다.

예제는 시작 화면에서 자동으로 열립니다. 교량 형식, 경간 배열, 상부 폭,
표고 등을 바꾸고 모델을 생성합니다. 경간 배열을 비우면 총연장과
기준 경간으로 균등 분할합니다. 검토표의 측점을 누르면 관련 부재와
대상이 강조되고 해당 위치가 확대됩니다.

프로젝트 JSON은 입력값을 보존합니다. 모델 JSON에는 객체 외곽,
선형 부재의 축과 두께, 경간 경계 및 검토 결과가 들어갑니다.
지장물의 좌표 순서는 측점, 횡방향, 표고이며 단위는 m입니다.

지원 범위는 직선 및 원곡선, 측점별 슬래브·지반 표고, 직육면체 현황과
대표 부재 형상입니다. 차량·건축한계는 예시 치수입니다. 선형 부재의
외접 상자 판정은 간섭 후보입니다. 실제 기준 적용과
기존 DXF·지형 데이터 연계는 후속 범위입니다.

지장물 CSV 및 한계 단면
-----------------------

지장물 및 검토 구역에서 예제 CSV를 내려받아 편집한 뒤 가져옵니다.
UTF-8 CSV의 열은 name, station_min, offset_min, elevation_min,
station_max, offset_max, elevation_max입니다. 좌표는 m 단위이며
시작점 접선 좌표계에서 X·Y·표고를 입력합니다. 직선에서는 X가
측점, Y가 횡방향 오프셋에 해당합니다.
가져오기는 지장물 목록을 교체합니다. 모델 생성 및 검토를 누르면
새 목록이 반영됩니다. 한 파일에서 최대 100개를 처리합니다.

선간격 및 한계 단면에서 복선 선간격과 차량·건축한계 폭 및 상단 높이,
두 단면의 공통 하단 높이를 설정합니다. 폭은 전체 폭이며, 높이는
해당 측점의 슬래브 표고 기준입니다. 설정값은 프로젝트 JSON에 저장됩니다.
이전 프로젝트는 초기 예시 치수를 사용합니다.


평면 선형 및 캔트
------------------

반경 0은 직선이며, 음수 반경은 좌곡선, 양수 반경은 우곡선입니다.
절댓값 60 m 이상, 교량 구간 원호각 90도 이하를 지원합니다.
원곡선 형상은 최대 5 m
측점 간격으로 분할하며, 사장 및 ED 케이블은 두 정착점 사이의
직선 형상으로 표시합니다.

지장물은 시작점 접선 기준의 직교 좌표에 고정됩니다. 교량 시작점은
(X, Y) = (시작 측점, 0)이며, +X는 시작 접선의 진행 방향,
+Y는 진행 방향 왼쪽입니다. CSV 열 이름은 이전 버전과 동일합니다.

기본 캔트는 0~200 mm 범위의 일정한 크기입니다. 곡선에서는 1435 mm를
기준으로 차량·건축한계 단면을 각 선로 중심에서 원 중심 쪽으로
기울입니다. 안쪽 레일이 낮고 바깥쪽 레일이 높습니다. 직선에서는 입력한
크기를 보존하면서 단면을 수직으로 유지합니다. 교량 부재는 수평을 유지합니다.
곡선 및 회전 단면은 분할 형상의 외접 상자로 검토하므로, 표시 거리와
측점은 후보의 근삿값입니다.

이전 프로젝트 JSON을 열 때 반경 부호를 반전해 곡선 방향을 보존하고
캔트는 절댓값을 사용합니다. 기울기는 새 규칙에 따라 자동 적용합니다.
새로 저장한 프로젝트에는 버전이 기록되어 다시 열 때 그대로 복원됩니다.


종단 선형
---------

종단 선형에 한 줄당 측점(m)과 슬래브 표고(m)를 쉼표로 구분해
2~100개 입력합니다. 측점은 오름차순이며 전체 교량 구간을 포함해야
합니다. 입력 사이의 표고는 직선 보간합니다. 비워 두면 기본 슬래브
표고를 전 구간에 적용합니다.

상부구조, 부속품, 아치 리브 및 차량·건축한계는 종단을 따라갑니다.
교각·교대·주탑의 하단과 기초는 해당 측점의 지반 표고를 기준으로 두고,
지점부 높이는 해당 측점의 슬래브 표고에 맞춥니다. 사장·ED 케이블은
정착점 사이의 직선 형상으로 유지합니다. 지장물은 입력 좌표에
고정됩니다. 종단을 따라가는 부재의 외접 상자 판정은 간섭 후보입니다.
종단 입력은 프로젝트 JSON에 저장됩니다.


측점별 지반 표고
----------------

지반선에 측점과 지반 표고(m)를 쉼표로 구분해 2~100개 입력합니다.
측점은 오름차순이며 전체 교량 구간을 포함해야 합니다. 빈 입력은
기본 지반 표고를 사용합니다. 입력점 사이의 표고는 직선 보간합니다.

기초 상단과 교각·교대·주탑 하단은 각 지점의 보간된 지반 표고에
배치합니다. 지반선을 입력한 경우 교량 전체 구간에서 슬래브와 지반의
표고 차가 4~150 m 범위인지 확인합니다. 이는 현재 모델의 입력 범위입니다.

3D 뷰의 갈색 점선은 교축 중심의 지반선입니다. 지반선 버튼으로
표시를 전환합니다. 프로젝트 JSON에는 지반 입력을, 모델 JSON에는
입력과 표시용 좌표를 저장합니다. 지반선은 종방향 기준선으로 표시되며,
지형면이나 지반과의 간섭 검토에는 직육면체 지장물 입력을 사용합니다.


지장물 유형 및 개별 최소 이격
-----------------------------

지장물 CSV에 선택 열 category 및 clearance_m을 추가할 수 있습니다.
유형 코드는 road(도로), waterway(하천), utility(지하 매설물),
rail(철도시설물), other(기타 지장물)입니다. 유형 열이나 셀이
비어 있으면 기타 지장물로 분류합니다. clearance_m이 비어 있으면
기본 지장물 이격을 사용합니다. 개별 이격은 0~100 m이며, 0 m도
명시적인 값입니다. 기존 7열 CSV도 그대로 가져올 수 있습니다.
프로젝트 JSON에서 지장물 유형은 category, 개별 이격은 clearance입니다.

결과 화면은 검토 대상 유형으로 필터링할 수 있습니다. 결과 CSV는
현재 필터와 관계없이 전체 결과를 포함하며 대상 유형과 실제로 적용한
최소 이격을 기록합니다. 모든 외부 지장물은 직육면체로 검토합니다.


IFC 내보내기
------------

저장소 루트에서 다음 명령으로 IFC 내보내기 의존성을 설치합니다::

    python -m pip install -r railspan/requirements-ifc.txt

모델 생성 및 검토 후 IFC 내보내기를 누르면 현재 생성된 모델로
railspan-model.ifc를 다운로드합니다. IFC4 삼각망에 교량 부재,
차량·건축한계, 지장물의 외곽을 담습니다. 단위는 m이며 좌표는 모델
JSON과 같은 시작점 접선 기준의 로컬 좌표입니다. 외부 좌표계 변환은
적용하지 않습니다. 검토 대상의 유형과 요구 이격은 IFC 속성에
저장하고, 간섭 결과표는 CSV로 내보냅니다.


교량 대안 비교
--------------

모델 생성 및 검토 후 교량 대안 비교에 이름을 입력하고 마지막 생성
모델을 저장합니다. 표에서 대안별 형식, 실제 경간 배열, 총연장,
지장물 수와 판정·후보 건수를 비교합니다. 지장물이 없는 대안에는
외부 검토 판정 불가를 표시합니다. 같은 검토 조건의 대안을 비교할
때는 지장물과 이격 설정을 동일하게 적용하세요.

열기를 누르면 저장된 입력을 양식에 복원하고 모델을 다시 계산합니다.
대안 목록은 현재 브라우저의 해당 주소 및 포트에 저장됩니다.
다른 브라우저나 PC로 옮기려면 대안을 연 뒤 프로젝트 JSON을
저장합니다.


종단·지반선 CSV 가져오기
-----------------------

종단 선형과 지반선의 예제 CSV를 각각 내려받을 수 있습니다.
UTF-8 CSV의 헤더는 ``station,elevation``이며, 두 값의 단위는
m입니다. 2~100개 측점을 오름차순으로 입력하고 중복 측점을 제거합니다.
가져오기에 성공하면 해당 입력란을 교체합니다. 입력란에서 값을 직접
편집할 수 있으며, 모델 생성 및 검토를 누르면 교량 구간 전체를
포함하는지 확인한 뒤 모델에 반영합니다.


부재 치수 편집
--------------

부재 치수에서 슬래브 두께, 거더 형고, 코핑과 받침의 높이,
기초의 두께·교축 방향 길이·횡방향 폭을 미터 단위로 지정합니다.
빈 입력은 기존 기본값을 사용합니다. 기본 거더 형고는 PSC 1.7 m,
그 밖의 형식은 2.2 m이며 기본 기초 폭은 상부 폭의 80%입니다.

슬래브 상단은 종단 표고를 따릅니다. 거더, 받침, 코핑은 그 아래에
순서대로 배치합니다. 기초 상단은 지점 지반 표고에 고정됩니다.
코핑 하단이 지반에 닿거나 내려가면 해당 교각·교대와 측점을 알려 줍니다.
직접 입력한 치수는 프로젝트 JSON에 저장하고, 실제 적용값은 모델 JSON에
기록합니다. 입력 범위와 높이 확인은 개념 모델의 형상 조건입니다.


부속품 배치
-----------

난간, 점검통로, 배수관로별로 양쪽·왼쪽·오른쪽·설치 안 함을
선택합니다. 좌우는 측점 증가 방향 기준입니다. 점검통로는 슬래브
가장자리 바깥으로 배치합니다. 난간은 같은 쪽에 통로가 있으면 통로
가장자리, 없으면 슬래브 가장자리에 배치합니다.

난간 높이와 통로 폭을 미터 단위로 입력합니다. 배수관은 외경,
슬래브 상단에서 관 중심까지의 하향 거리, 슬래브 가장자리에서 관
중심까지의 안쪽 거리를 설정합니다. 관의 외경은 개념 검토용
정사각형 단면의 치수로 사용합니다. 부속품은 교량 전 구간에 적용되며
종단과 평면 선형을 따릅니다. 기존 프로젝트의 기본 배치는 양쪽입니다.


아치 형상 편집
--------------

아치교를 선택하면 아치 형상에서 포물선 또는 원호 축선, 리브 두께,
경간·리브당 행어 수(1~24개)를 설정할 수 있습니다. 포물선, 0.65 m,
행어 5개가 기본값입니다. 라이즈는 아치 시·종점에서 슬래브 기준
최고점까지의 높이이며, 원호에서는 각 경간 길이의 절반 이하여야 합니다.

각 경간 양쪽에 리브를 배치합니다. 행어는 측점 간격을 균등하게
배분하고 리브와 만나는 위치를 리브 분할점으로 사용합니다.
출력은 하로식 아치의 개념 형상이며, 라이즈와 두께는 구조 검토용
치수가 아닙니다. 설정은 프로젝트와 모델 JSON에 반영됩니다.


사장교·ED교 케이블 배치
----------------------

사장교 또는 ED교를 선택하면 주탑 높이, 케이블 면 수(교축 중심의
1면 또는 양쪽 2면), 경간·면당 케이블 수(1~12개)와 상부 정착점
범위를 설정할 수 있습니다. 주탑 높이는 슬래브 상단에서 주탑
상단까지의 거리입니다. 빈 입력은 사장교에서 기준 높이, ED교에서
기준 높이의 절반을 적용합니다.

정착점 비율은 주탑에서 인접 지점까지의 거리 대비 백분율입니다.
케이블이 여러 개면 설정 범위 양 끝을 포함해 균등하게 배치하고,
한 개면 범위 중앙에 배치합니다. 기본값은 양측 2면, 경간·면당
4개, 정착점 25~85%입니다. 주탑은 기존 지점 배치에 따릅니다.
설정값은 프로젝트 및 모델 JSON에 반영됩니다.


포물선 종단곡선
---------------

종단 선형의 측점·표고는 접선 교점으로 입력합니다. 종단곡선 입력란에
``변곡점 측점, 곡선 길이``를 한 줄씩 입력하면 지정한 내부 변곡점을
중심으로 대칭 포물선이 적용됩니다. 곡선 길이는 0.01 m 이상입니다.
예를 들어 종단 선형이 ``0, 15`` / ``55, 16.5`` / ``110, 15``일
때 ``55, 40``을 입력하면 측점 35~75 m 구간이 포물선으로 연결됩니다.

곡선은 인접 변곡점 범위 안에 있어야 하며 서로 겹칠 수 없습니다.
지정하지 않은 구간에는 기존의 직선 보간을 적용합니다. 슬래브와
지반의 표고 차는 곡선 내 최솟값과 최댓값을 포함해 확인합니다.
화면 및 내보내기 형상은 곡선을 분할해 표현하며, 간섭 판정은
외접 상자 기준 후보로 표시합니다. 입력값은 프로젝트 JSON에 저장됩니다.


측점별 캔트
-----------

평면 선형 및 캔트에서 ``측점, 캔트``를 한 줄씩 입력합니다.
측점은 m, 캔트는 mm입니다. 2~100개 측점을 오름차순으로 입력하며,
교량 전 구간을 포함해야 합니다. 캔트 값을 0~200 mm 사이에서
직선 보간한 뒤 선로별 한계 단면의 회전각을 계산합니다.
입력란을 비워 두면 기본 캔트를 적용합니다.

원곡선에서는 해당 측점의 캔트에 따라 한계 단면이 원 중심
쪽으로 기울어집니다. 직선에서는 입력한 값을 저장하고 한계 단면은
수직을 유지합니다. 설정은 프로젝트 JSON과 모델 JSON에 기록되며,
IFC에는 해당 한계 단면 형상이 반영됩니다.


복합 평면 선형
--------------

평면 선형 구간에 ``끝 측점, 반경``을 한 줄씩 입력합니다.
첫 구간은 교량 시작 측점에서 시작하며, 다음 구간은 직전 구간 끝에서
시작합니다. 마지막 구간은 교량 종점에서 끝나야 합니다. 예를 들어
0~110 m 교량에서 ``20, 0`` / ``65, -250`` / ``110, 300``을
입력하면 직선, 좌곡선, 우곡선이 접선 방향을 이어서 연결됩니다.
입력을 비우면 기본 반경으로 한 구간을 구성합니다.

최대 100구간, 곡선 반경 절댓값 60 m 이상, 각 구간 회전각 절댓값의
합 90도 이하를 지원합니다. 직선과 곡선이 만나거나 곡선 방향이 바뀌는
측점은 캔트를 0 mm로 지정해야 합니다.
지장물과 IFC 좌표는 기존과 같이 시작점 접선 좌표계를 사용합니다.


클로소이드 완화곡선
------------------

평면 선형 구간의 완화곡선 행에는 ``끝 측점, 시작 반경, 끝 반경``을
입력합니다. 반경 0은 직선입니다. 앞·뒤 구간이 있으면 접속점에서
양쪽 반경을 동일하게 입력하세요. 한 완화곡선에서 좌·우 방향을
바꿀 수 없습니다. 직선 쪽 끝에서 캔트는 0 mm로 지정합니다.
완화곡선 내부의 캔트는 기존 측점별 캔트로 조정합니다.

0~110 m 교량에서는 ``20, 0`` / ``40, 0, -250`` /
``75, -250`` / ``95, -250, 0`` / ``110, 0``처럼 입력할 수 있습니다.
완화곡선의 곡률은 거리에 비례해 바뀝니다. 모델과 IFC는 분할 형상을
사용하고 간섭 검토 측점은 가장 가까운 교축 위치의 근삿값입니다.


평면 선형·캔트 CSV 가져오기
----------------------------

평면 선형 및 캔트에서 각각 예제 CSV를 내려받을 수 있습니다.
두 예제는 0~110 m 교량의 동일한 선형에 맞춰 작성되었습니다.

평면 선형 CSV의 헤더는 ``end_station,start_radius,end_radius``입니다.
측점과 반경 단위는 m입니다. 직선·원곡선은 end_radius를 비워 두고,
완화곡선은 끝 반경을 입력합니다. 끝 반경 0은 직선으로 이어지는
완화곡선을 뜻합니다. 끝 반경 열 자체를 생략할 수도 있습니다.

캔트 CSV의 헤더는 ``station,cant_mm``입니다. 측점은 m,
캔트는 mm 단위입니다. UTF-8로 저장하고 측점을 오름차순으로
정렬하세요. 가져오면 해당 입력란이 교체됩니다. 모델 생성 및 검토에서
교량 구간 전체의 범위와 접속부 캔트 조건을 확인합니다.


도로·하천 수직 이격
--------------------

지장물 CSV의 선택 열 clearance_mode에 vertical을 지정하면 도로
또는 하천 검토 구역과 평면에서 면적으로 겹치는 부재를 수직으로
검토합니다. 구역 상단 표고(elevation_max)에서 부재 하단까지의
차를 계산합니다. 구역 하단 이하거나 평면에서 경계만 닿는 부재는
수직 이격 대상으로 잡지 않습니다. 결과표와 CSV에서 음수는 구역
상단 아래로의 침범, 0은 상단 접촉, 양수는 수직 여유입니다.
요구 이격을 충족하면 결과 목록에 나타나지 않습니다.

clearance_mode가 비어 있거나 spatial이면 기존 공간 이격 방식을
사용합니다. 곡선이나 경사 부재 등은 외접 상자 기준 후보로
표시합니다. IFC 검토 대상 속성에도 이격 방식을 기록합니다.


구역별 최소 수직 이격
---------------------

구역별 최소 수직 이격 표에서 수직 방식으로 검토한 각 도로·하천의
최소 이격, 요구값, 최솟값을 결정한 부재와 측점을 확인할 수
있습니다. 측점을 선택하면 해당 부재가 3D 뷰에서 강조됩니다.
요구값을 충족한 구역도 표시하며, 검토 구역에 해당하는 부재가
없으면 계산값 없이 해당 부재 없음으로 표시합니다.

수직 이격 요약 CSV에는 구역별 한 행을 내보냅니다. 기존 간섭 및
이격 결과와 결과 CSV에는 계속 침범·접촉·이격 미달 항목을 기록합니다.


부재 목록
---------

부재 목록에서 유형을 선택하고 부재 ID를 누르면 3D 뷰에서
해당 부재가 강조됩니다. 부재 ID는 현재 생성한 모델의 객체 ID이며
모델 JSON과 IFC의 Tag에서 확인할 수 있습니다. 측점 범위는 평면
선형을 적용하기 전 부재의 교축 방향 외곽이며, 표고는 변환한 부재
외접 범위의 최저·최고값입니다. 기초나 선형 부재의 외곽은 교량
시·종점 측점을 벗어날 수 있습니다.

전체 부재 CSV는 현재 유형 필터와 관계없이 교량 부재를 모두
내보냅니다. 차량·건축한계와 외부 지장물은 검토 대상에 표시됩니다.
