Railspan | 철도 교량 개념설계 시제품
======================================

저장소 루트에서 Python 3.9 이상으로 `python -m railspan`을
실행하고 http://127.0.0.1:8765 를 브라우저에서 엽니다.
포트를 바꾸려면 `--port 8766`을 붙입니다. 별도 패키지 설치 없이
실행하며, 서버는 현재 PC의 루프백 주소에만 연결합니다.

예제는 시작 화면에서 자동으로 열립니다. 교량 형식, 경간 배열, 상부 폭,
표고 등을 바꾸고 모델을 생성합니다. 경간 배열을 비우면 총연장과
기준 경간으로 균등 분할합니다. 검토표의 측점을 누르면 관련 부재와
대상이 강조되고 해당 위치가 확대됩니다.

프로젝트 JSON은 입력값을 보존합니다. 모델 JSON에는 객체 외곽,
선형 부재의 축과 두께, 경간 경계 및 검토 결과가 들어갑니다.
지장물의 좌표 순서는 측점, 횡방향, 표고이며 단위는 m입니다.

지원 범위는 직선 선형, 일정한 슬래브·지반 표고, 직육면체 현황과
대표 부재 형상입니다. 차량·건축한계는 예시 치수입니다. 선형 부재의
외접 상자 판정은 간섭 후보입니다. 실제 기준 적용, 곡선·캔트,
기존 DXF·지형 데이터 연계 및 IFC 내보내기는 후속 범위입니다.
