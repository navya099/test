# 건넘선 설계 엔진 - 설계 노트

## 1. 프로그램의 목적
주어진 트랙 오프셋(Offset)과 건넘선 설치 길이(L)에 대해,
CAD 도면과 일치하는 최적의 분기기 제원(R, θ, cl, sl)을 산출한다.

## 2. 수학적 모델 (곡선-직선-곡선 형상)
- 총 길이: 2*cl + sl = L
- 총 횡이동: 2*R*(1-cosθ) + sl*sinθ = Offset
- 곡선장과 각도: R = cl / θ
=> θ에 대한 비선형 방정식이므로 이진 탐색(Bisection)으로 해를 구한다.

## 3. 제약조건
- cl: 25m의 배수
- sl: 12.5m의 배수
- 최소 반지름(MIN_RADIUS) 및 목표 반지름(TARGET_RADIUS)을 만족하는 해 선택

## 4. CAD 검증 이력
- L=100, Offset=7m: cl=25, sl=50, R≈358.5m, θ≈8° (도면 일치)
- L=200, Offset=7m: cl=50, sl=100, R≈1071.1m, θ≈2.6718° (도면 일치)
